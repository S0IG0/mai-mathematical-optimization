# Запуск всех работ через Docker

Все 5 лабораторных работ по методам оптимизации запускаются одной командой.
Каждая работа — это Spring Boot backend + React/Vite frontend (за nginx).
Отдельная **hub-страница** служит единой точкой входа со ссылками на все работы.

## Архитектура

```
Браузер ──► :8080  hub (nginx)            единая точка входа со ссылками
        ──► :8081  web-1 ──► /api,/ws ──► backend-1   одномерная оптимизация
        ──► :8082  web-2 ──────────────► backend-2   многомерная оптимизация
        ──► :8083  web-3 ──────────────► backend-3   градиентные методы
        ──► :8084  web-4 ──────────────► backend-4   условия Куна–Таккера
        ──► :8085  web-5 ──────────────► backend-5   штрафные/барьерные функции
```

- Каждый `web-N` (nginx) отдаёт собранный фронт и проксирует `/api` и `/ws`
  на свой `backend-N`. Стили и логика каждой работы сохранены без изменений.
- Backend'ы наружу не публикуются — доступ только через свой фронт.

## Запуск

Нужен установленный Docker Desktop.

```bash
# собрать и поднять всё (первый раз сборка займёт несколько минут)
docker compose up --build -d
```

Открыть точку входа: **http://localhost:8080**

Прямые ссылки на работы:

| Работа | URL                    |
|--------|------------------------|
| 1      | http://localhost:8081  |
| 2      | http://localhost:8082  |
| 3      | http://localhost:8083  |
| 4      | http://localhost:8084  |
| 5      | http://localhost:8085  |

## Управление

```bash
docker compose ps                 # статус контейнеров
docker compose logs -f web-2      # логи конкретного сервиса
docker compose down               # остановить и удалить контейнеры
docker compose up --build -d web-3 backend-3   # пересобрать одну работу
```

## Порты

Если порты `8080–8085` заняты, поменяйте левую часть `ports:` в
`docker-compose.yml` (например, `"9081:80"`) и пересоберите.
