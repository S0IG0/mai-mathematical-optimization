# Задание 4: Условия оптимальности Джона и Куна-Таккера

Приложение для решения всех 18 вариантов лабораторной работы по условной оптимизации.

## Запуск

### Backend (Spring Boot, порт 8080)

```bash
cd backend
mvn spring-boot:run
```

### Frontend (Vite + React, порт 5173)

```bash
cd frontend
npm install
npm run dev
```

Откройте http://localhost:5173

## Стек

- **Backend:** Java 21, Spring Boot 2.7 — перечисление вершин допустимой области, проверка ККТ, построение контура
- **Frontend:** React, Vite, MUI, Plotly — интерактивный график, таблица кандидатов, условия ККТ
