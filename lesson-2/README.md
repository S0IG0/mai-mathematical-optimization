# Задание 2: Методы многомерной оптимизации

Веб-приложение для лабораторной работы по курсу «Теория оптимального планирования и управления (безусловная оптимизация)».

## Стек

- **Backend:** Java 21, Spring Boot 2.7
- **Frontend:** React 18, Vite, Material UI

## Запуск

### Backend

```bash
cd backend
./mvnw spring-boot:run
```

Сервер: http://localhost:8080

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Интерфейс: http://localhost:5173

## Возможности

- **WebSocket** (`/ws/optimize`) — траектория рисуется на графике по мере расчёта
- 16 вариантов задания из методички
- Методы: Розенброка, Хука–Дживса, Гаусса–Зейделя (дискретный и непрерывный шаг)
- Выбор F₁ / F₂, начальной точки, ε и Δ
- Таблица итераций (K, Xk, F(Xk), j, dj, yj, λ/Δ, yj+1)
- Линии уровня (тепловая карта) и траектория метода для 2D-функций F₁
- Сравнение режимов Гаусса–Зейделя с/без одномерной оптимизации
