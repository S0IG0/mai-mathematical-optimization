# Задание 5: Методы штрафных и барьерных функций

Веб-приложение для решения всех 18 вариантов лабораторной работы по курсу «Теория оптимального планирования и управления (безусловная оптимизация)».

## Стек

- **Backend:** Java 21, Spring Boot 2.7
- **Frontend:** React 18, Vite, MUI, Plotly

## Запуск

### Backend

```bash
cd backend
./mvnw spring-boot:run
```

Сервер: http://localhost:8080

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Интерфейс: http://localhost:5173

## Возможности

- Выбор варианта 1–18 с автоподстановкой функции, ограничений и пресетов μ
- Методы штрафных и барьерных функций с таблицей K, μₖ, Xₖ₊₁, F, α/B, Θ(μ), μ·α/μ·B
- График линий уровня, ограничений и траектории оптимизации (Plotly)
- Специальные эксперименты по заданию (сравнение множеств X, стратегии μ и т.д.)
